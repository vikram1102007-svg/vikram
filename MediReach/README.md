# MediReach

Static responsive demonstration for medicine-availability discovery at government health centres.

## Features
- Medicine search and quick-search chips
- Rule-based freshness labels: Recently verified, Needs confirmation, Outdated
- Facility address display and Google Maps address-search links
- Responsive mobile layout
- Clear warning about sample data

## Run locally
Open index.html in a browser. No build tools are required.

## Limitations and safety
This is a reconstruction based on the MediReach requirements available in the conversation, not an export of the original deployed source. Facility names, addresses, stock levels and timestamps are fictional sample data. Google Maps links search sample address text and are not verified facility locations. No live inventory, backend, authentication, SMS/IVR, government integration or feedback transmission is included. Confirm availability directly with the health centre. MediReach does not diagnose, prescribe or recommend medicine substitutions.

## Demo freshness rules
0–24 hours: Recently verified; 24–72 hours: Needs confirmation; over 72 hours: Outdated. Validate thresholds with an authorised pilot partner before real-world use.
